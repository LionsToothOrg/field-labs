# Investigation-first presentation

Field Labs should make the engineering investigations more visually interesting than the shell around them.

The home view therefore stays compact and routes attention into the bench. Individual investigations can use richer diagrams, traces, controls, and state changes when those elements explain the system under study.

Avoid generic product-landing patterns such as oversized promotional headlines, decorative hero graphics that consume the first viewport, feature-card grids presented as products, or visual effects without an explanatory role.
